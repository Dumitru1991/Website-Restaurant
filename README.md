# Restaurant Website – Concept

A concept website for a restaurant, built with **HTML, CSS and JavaScript**. It is a static front-end project that presents a restaurant online with a modern layout, images and video.

🍽️ **Live demo:** [dumitru1991.github.io/Concept_Restaurant](https://dumitru1991.github.io/Concept_Restaurant/)

## Features

- Single-page restaurant website
- Visual presentation with images and video
- Clean, responsive layout
- Lightweight static site: no backend, framework or build tools needed

## Tech Stack

- HTML5
- CSS3
- JavaScript (vanilla)

## Project Structure

```
Website-Restaurant/
├── css/          Stylesheets
├── img/          Images
├── js/           JavaScript files
├── video/        Video content
└── index.html    Main page
```

## Getting Started

### View online

Open the live demo: https://dumitru1991.github.io/Concept_Restaurant/

### Run locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/Dumitru1991/Website-Restaurant.git
   ```
2. **Open the project folder**
   ```bash
   cd Website-Restaurant
   ```
3. **Open `index.html`** in your browser (double-click it, or use a local server such as the VS Code **Live Server** extension).
